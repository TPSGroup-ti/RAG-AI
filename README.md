## ✅ ความสามารถหลัก

- 🌐 **อ่านเว็บ/ลิงก์** — ดึงเนื้อหาจาก URL มาเป็นความรู้
- 📄 **อ่านไฟล์/โค้ด** — รองรับ .txt, .md, .json, .py, .js และอื่นๆ
- 🔌 **อ่าน API** — ดึงข้อมูล JSON จาก API มาแปลงเป็นความรู้
- 🧠 **ระบบ RAG** — แบ่งข้อมูล→จัดเก็บ→ค้นหาอัตโนมัติ
- 🤖 **ถาม-ตอบจากความรู้** — AI ตอบโดยใช้เฉพาะข้อมูลที่คุณให้มา
- ✅ **ตรวจสอบและปรับปรุง** — ให้คะแนนคำตอบ ระบบเรียนรู้จากคุณ
- 📤 **ส่งออกความรู้** — ดาวน์โหลดฐานความรู้ทั้งหมด เก็บ/ย้ายได้ตลอด
- 📥 **นำเข้าความรู้** — ย้ายความรู้ไปติดตั้งที่อื่นได้ทันที
- 🔑 **แยกผู้ใช้ด้วย Token** — แต่ละคนมีฐานความรู้ส่วนตัวแยกกัน
